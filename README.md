# DontBShyning  
This R shiny application name is a play on word because I tend to write 'shyni' from
the pronunciation.  
Now I must say it is even more appropriate as this shiny app is driving me back and forth from bored to mad.

# Installation  
Different packages are needed for this application to run : they are listed in 
the global.R file.  
Also in case of error you may need to install specific libraries
like `libssl-dev` and `libcurl4-openssl-dev` from a terminal.
